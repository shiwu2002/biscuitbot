# 全能设计方法论

面向从平面到品牌、UI、新媒体视觉的设计需求。先确认用途与规格，再按品类流程产出一份「需求 + 设计思路 + 落地路径」的方案，让非设计师也能照着执行。

## 需求确认清单（动手前先问清）

1. 用途：海报 / Logo / 封面 / 电商主图 / 社媒配图 / 品牌视觉？
2. 规格：尺寸（横竖版、比例）、分辨率、投放渠道；
3. 风格：参考方向（简约 / 复古 / 潮酷 / 治愈 / 商务…），有没有对标作品；
4. 品牌信息：品牌名、口号、主色、字体、Logo 素材；
5. 文案：必须出现的文字、层次（主标题 / 副标题 / 卖点 / 行动号召）。

## 设计基本原则

- **色彩**：主色 1 + 辅色 1–2 + 中性色（黑/白/灰）；同一画面主色占比 ≥60%；避免高饱和撞色过多。
- **字体排版**：标题用粗且有区分度的字体，正文清晰易读；层级按「主标题 > 副标题 > 正文 > 注脚」递减；字号与行距成比例。
- **构图**：视线引导（对角 / Z 字 / 中心聚焦）；留白给内容呼吸；元素对齐、间距一致。
- **统一性**：同一系列视觉使用一致的主色、字体与版式。

## 品类流程与自查清单

### 海报
流程：定主题 → 定构图（信息层级）→ 配图/背景 → 排版 → 输出。
自查：主标题 3 秒内能读清？行动信息（时间/地点/报名方式）显眼？有无多余元素？

### Logo
流程：关键词提炼 → 草稿（字形 / 图形 / 组合）→ 简化 → 单色与反白版 → 输出。
自查：缩小后仍清晰？单色下可识别？是否容易被记住与模仿？

### 封面（短视频 / 公众号 / 专辑）
流程：定封面三要素（吸引点 + 利益点 + 辨识元素）→ 大字号标题 → 留视觉锚点 → 输出。
自查：小图尺寸下标题可读？与正文风格一致？点开欲望强不强？

### 电商主图
流程：定卖点 → 产品图 + 卖点标签（1–3 个）→ 场景/背景 → 排版 → 输出。
自查：产品清晰完整？核心卖点一眼可见？符合平台尺寸规范？不夸大、不违规词？

### 社媒配图（小红书 / 公众号 / 朋友圈）
流程：定内容主题 → 统一模板（色系/字体/版式）→ 配图 + 文字排版 → 输出。
自查：竖版适配手机阅读？系列内容风格统一？文字与图片不打架？

## 执行要点

- 需求含糊时，先给「确认清单」让用户补全，再给方案，不要直接凭空做。
- 输出要具体：给出配色十六进制、字体建议、构图草图说明与产出路径（用什么工具/文件格式），让用户能落地执行。

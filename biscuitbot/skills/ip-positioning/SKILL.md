# IP 定位访谈方法论

面向想打造个人 / 品牌 IP 的用户（如「我想做个博主」「想靠副业变现」），通过结构化访谈逐步引导，输出一份可直接执行的定位文档。**不要**直接丢模板，先用提问把模糊想法变清晰。

## 使用时机

- 用户想做个人 IP / 账号，但没有明确方向；
- 品牌想重新定位或梳理差异化；
- 已有账号但内容方向混乱、涨粉停滞、变现不清晰。

## 结构化访谈提纲（按顺序推进，每项追问到具体）

1. 优势与能力：你擅长什么？别人经常夸你什么？有什么技能或资源是别人不容易复制的？
2. 热情与动机：什么事情让你愿意长期投入？你希望这个 IP 帮你实现什么（影响力 / 收入 / 人脉 / 表达）？
3. 目标受众：你最想服务 / 吸引的人是谁？TA 们有什么痛点、渴望、消费习惯？
4. 独特价值：同一方向上已有谁？你和 TA 们相比，差异点在哪（人设 / 内容形式 / 经历 / 交付）？
5. 变现路径：你更倾向哪种变现——广告、付费内容、社群、咨询、电商，还是带货？短期靠什么、长期靠什么？

## 提炼公式（每个问题产出可写进文档的句子）

- **一句话定位**：`我是谁 + 帮助谁 + 解决什么 + 凭什么（独特价值）`
- **差异化卖点（USP）**：从「受众 × 场景 × 能力」交集里挑 1–2 个最锋利的点
- **人设标签**：3–5 个可被记住的标签（性格 + 领域 + 结果导向）

## 定位文档模板（最终交付结构）

1. 受众画像：年龄 / 场景 / 痛点 / 渴望（2–3 类主画像）
2. 价值主张：一句话定位 + 差异化卖点
3. 人设与内容方向：3 个内容栏目（每个含：目标、形式、更新频率、选题示例）
4. 内容栏目与账号结构
5. 变现路径：短期（3 个月）与长期（1 年）的变现方式与所需条件
6. 落地动作：未来 2 周可执行的 3–5 个具体动作（如发 5 条内容测试哪个栏目反馈最好）

## 执行要点

- 一次访谈聚焦一个核心问题，不要一次塞满；用户答不出的地方，换成「给我举一个例子」引导。
- 定位文档用白话写，让用户看完知道明天该做什么。
- 若用户已经比较清晰，跳过泛问，直接针对空白点深挖。

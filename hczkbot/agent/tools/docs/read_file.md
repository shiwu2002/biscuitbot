# read_file

读取指定路径文件的内容。

## 何时使用

需要查看文件内容、分析代码逻辑或检查配置文件时使用。支持按行范围读取，适合读取大文件的部分内容，避免一次性加载过多数据。

## 参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| path | string | 是 | - | 要读取的文件绝对路径 |
| start_line | integer | 否 | 1 | 起始行号 |
| end_line | integer | 否 | 末尾 | 结束行号 |

## 调用示例

```
read_file(path="/etc/hosts")
```

```
read_file(path="/var/log/app.log", start_line=100, end_line=200)
```

## 注意事项

- path 必须为绝对路径，相对路径会导致错误
- 大文件建议使用 start_line 和 end_line 分段读取
- 不存在的文件会返回错误，请先确认路径有效
- 二进制文件可能无法正确显示内容

# unregister_tool

卸载已注册的自定义工具。

## 何时使用

需要移除不再使用的自定义工具、清理工具集或替换工具实现时使用。通过工具名称卸载，适合维护工具系统。

## 参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| name | string | 是 | - | 要卸载的工具名称 |

## 调用示例

```
unregister_tool(name="my_tool")
```

## 注意事项

- name 必须为已注册的工具名称
- 卸载后该工具不可再被调用
- 内置工具通常不可卸载
- 卸载不影响已加载的会话状态

# long_task

定义长周期任务的目标和步骤。

## 何时使用

需要执行多步骤、耗时的复杂任务时使用。通过明确目标和步骤分解任务，便于跟踪进度和保持上下文。

## 参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| title | string | 是 | - | 任务标题 |
| description | string | 否 | - | 任务详细描述 |
| steps | array | 否 | - | 任务步骤列表 |

## 调用示例

```
long_task(title="重构认证模块", description="将 session 改为 JWT", steps=["分析现状", "设计接口", "实施改造", "编写测试"])
```

## 注意事项

- title 应简洁概括任务目标
- steps 建议按执行顺序排列
- 长任务执行中可逐步更新进度
- description 帮助子代理理解任务背景

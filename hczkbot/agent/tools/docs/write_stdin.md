# write_stdin

向运行中的进程写入输入。

## 何时使用

需要与运行中的交互式进程通信、应答提示或发送输入时使用。配合 exec 启动的会话使用，适合处理交互式程序。

## 参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| session_id | string | 是 | - | 执行会话 ID |
| text | string | 是 | - | 写入 stdin 的文本 |

## 调用示例

```
write_stdin(session_id="abc123", text="yes\n")
```

## 注意事项

- session_id 必须为有效的运行中会话
- text 末尾通常需加换行符 \n
- 进程已结束时会返回错误
- 仅对等待 stdin 输入的进程有效

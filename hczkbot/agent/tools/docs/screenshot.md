# screenshot

截取屏幕并分析内容。

## 何时使用

需要查看当前屏幕状态、分析 UI 界面或基于视觉信息决策时使用。结合视觉模型理解截图内容，适合 GUI 自动化和界面调试。

## 参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| question | string | 是 | - | 针对截图提出的问题或分析目标 |

## 调用示例

```
screenshot(question="当前页面是否有报错弹窗？如有请描述内容")
```

## 注意事项

- question 决定分析方向，应具体明确
- 截图会捕获整个屏幕，请确保无敏感信息泄露
- 依赖图形界面环境，无头环境不可用
- 分析结果基于视觉模型，复杂场景可能不准确

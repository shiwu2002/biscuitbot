# list_dir

列出指定目录下的文件和子目录。

## 何时使用

需要查看目录结构、定位文件或确认目录内容时使用。支持递归列出子目录，适合快速了解项目结构。

## 参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| path | string | 是 | - | 目录绝对路径 |
| recursive | boolean | 否 | false | 是否递归列出子目录 |
| max | integer | 否 | - | 返回条目最大数量 |

## 调用示例

```
list_dir(path="/var/log")
```

```
list_dir(path="/home/user/project", recursive=true, max=100)
```

## 注意事项

- path 必须为绝对路径
- 递归列出大目录可能返回大量结果，建议配合 max 使用
- 隐藏文件（以 . 开头）默认会被列出
- 目录不存在或无权限时会返回错误

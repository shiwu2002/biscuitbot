 # screenshot

对当前屏幕截图并使用视觉模型分析。

## 何时使用

需要了解当前屏幕状态、理解 UI 界面、识别屏幕上的元素或内容时使用。特别适合桌面自动化和 UI 理解场景。

## 参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| question | string | 是 | - | 关于当前屏幕状态的问题，视觉模型会基于截图回答 |

## 调用示例

```
screenshot(question="当前是什么应用程序在前台？")
screenshot(question="屏幕上有没有错误弹窗？内容是什么？")
screenshot(question="浏览器地址栏的 URL 是什么？")
```

## 注意事项

- 需要配置 visionModel
- 返回视觉模型对截图的分析结果，而非原始图片
- 适用于 GUI 自动化、UI 测试等场景

# unregister_tool

卸载已注册的自定义工具。

## 何时使用

需要移除不再使用的自定义工具、清理工具集或替换工具实现时使用。通过工具名称卸载，内置工具无法卸载。

## 参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| name | string | 是 | - | 要卸载的工具名称（1-100 字符） |

## 调用示例

```
unregister_tool(name="my_tool")
```

## 注意事项

- name 必须为通过 register_tool 注册的自定义工具名称
- 内置工具无法卸载
- 卸载后该工具不可再被调用

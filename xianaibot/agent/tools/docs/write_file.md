# write_file

写入或覆盖文件内容（仅文本文件）。

## 何时使用

需要创建新文件、覆盖已有文件内容或保存生成结果时使用。会直接覆盖目标文件，适合一次性写入完整内容，不适用于部分编辑。

## 参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| path | string | 是 | - | 文件路径 |
| content | string | 是 | - | 要写入文件的文本内容 |

## 调用示例

```
write_file(path="/tmp/test.txt", content="Hello World")
```

## 注意事项

- 如果文件已存在会被完整覆盖，请谨慎操作
- 父目录不存在时会自动创建
- 不会追加内容，需追加请使用 exec 配合重定向
- 仅支持文本文件，二进制内容请使用其他方式

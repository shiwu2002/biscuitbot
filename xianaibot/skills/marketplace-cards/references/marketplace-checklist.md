# 电商上架交付物清单

`marketplace-cards` 的按需加载参考。这份清单是**「有没有交付到位」的核对标准**——
按它逐项和用户确认范围，生成后按它逐项自检。

## 一、常用范围

先问用户要哪一档，别默认做全套（费时费额度）：

| 范围 | 包含 |
|---|---|
| 只做主图 | 1 张主图 |
| 主图 + 副图 | 主图 + 5 张副图 |
| 主图 + A+ | 主图 + 7 个 A+ 模块 |
| 全套 | 主图 + 5 张副图 + 7 个 A+ 模块 |

用户想要自定义组合时，直接按下面的交付物清单点单即可。

## 二、13 个交付物

### 主图与副图

| 名称 | 这张图要解决什么 |
|---|---|
| `main_image` | **搜索列表里的第一眼。** 让用户一眼看清是什么产品、什么品牌——通常要求干净背景、产品占主体 |
| `infographic` | **把卖点讲清楚。** 用图示 + 短文案把核心参数/成分/功能点视觉化，让人不用读详情页就懂 |
| `multi_angle` | **打消「到底长什么样」的疑虑。** 同一产品的正面/侧面/背面/细节多角度展示 |
| `detail_shot` | **证明做工。** 材质、纹理、缝线、接口、包装细节的微距特写 |
| `lifestyle` | **让人代入使用场景。** 产品在真实生活/工作环境里被使用的样子 |
| `whats_in_box` | **降低收货预期落差。** 展示包装盒里到底有什么，配件一件不落 |

### A+ 内容模块

A+ 是详情页里可自由排版的图文区，下面 7 个模块是一套完整的说服链：

| 名称 | 这张图要解决什么 |
|---|---|
| `aplus_hero_banner` | **开场定调。** 宽幅品牌形象图，一句话说清产品定位 |
| `aplus_pain_points` | **唤起共鸣。** 把用户的痛点场景画出来，让他觉得「说的就是我」 |
| `aplus_features` | **给出解法。** 核心功能逐条图示化，对应上面的痛点 |
| `aplus_ingredients` | **建立信任（成分/用料）。** 原料、材质、配方——适合美妆、食品、家纺 |
| `aplus_efficacy` | **证明有效。** 效果对比、数据可视化、用户反馈——适合功效类产品 |
| `aplus_how_to_use` | **降低使用门槛。** 步骤图，让用户知道买回去怎么用 |
| `aplus_endorsement` | **临门一脚。** 权威背书、检测报告、媒体露出、销量口碑 |

> 不是每个产品都需要全部 7 个模块。食品/美妆重 `ingredients` 与 `efficacy`，
> 工具/数码重 `features` 与 `how_to_use`。和用户确认哪几个真正相关。

## 三、主图合规要点（通用原则）

以下是**通用**做法，绝大多数平台都要求：

- **背景干净**：纯白或极简背景，不要出现与产品无关的道具、人物、场景
- **产品占主体**：产品在画面中占比要高，缩略图下也要能看清是什么
- **不要杂项**：主图上通常不允许出现促销文字、价格、水印、边框、拼接多图
- **多角度图与主品一致**：`multi_angle` 里的产品外观必须和主图是同一件，不能有色差或改款
- **A+ 模块可以放开**：A+ 区允许信息图、场景图、文字排版，不受主图的极简限制

> ⚠️ **平台规则会变，且各平台不同。** 具体的像素尺寸、白底色值、产品占比下限、
> 允许的文字面积比例、是否允许模特出镜等，**以用户实际要上架的平台当前规则为准**。
> **不确定就直接问用户，或让用户去平台后台/规则页确认——不要凭印象编一个数字。**
> 编错比不编的代价大得多。

## 四、同链接一致性纪律

同一商品链接下的所有图**必须看起来是一套**，否则用户会觉得是拼凑的：

1. **先做主图**，和用户确认产品外观（包装、颜色、logo、材质）与视觉语言（光线方向、
   色调、背景风格）都对了。
2. **把主图作为后续所有图的 `reference_images` 传入**——这是锚定产品外观与视觉系统的
   唯一可靠手段。不传参考图、每张独立生成，产品一定会走样。
3. 整套图共享同一套**光线语言**与**色调**，副图与 A+ 之间也不要跳跃。
4. 生成后**横向比对**一遍：把主图和其余图放一起看，产品颜色、logo 位置、包装形状
   有没有变化。有变化就重做那张。

## 五、交付前自检

- [ ] 确认的范围内的交付物**全部产出了**，没有漏项
- [ ] 主图背景干净，无多余文字/水印/边框
- [ ] 整套图里产品外观**完全一致**
- [ ] 画面里的文字**逐字核对无误**（错了换擅长文字渲染的模型重做那张，不要硬交付）
- [ ] 失败的图已如实告知用户，没有用别的图充数

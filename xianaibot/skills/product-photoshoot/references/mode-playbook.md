# 产品摄影模式手册

`product-photoshoot` 的按需加载参考。**选定模式后读对应小节**，按「提示词骨架」的顺序
把追问得到的答案扩写成完整提示词。画幅是**惯例建议**，不是模型约束——用户明确要求时以用户为准。

通用提醒：**有产品图就必须传 `reference_images`**，并在提示词里显式要求保持产品外观一致。

---

## product_shot —— 影棚成品图

**骨架**：产品外观（材质 / 颜色 / 形状 / 包装上的文字）→ 背景（无缝纸 / 纯色 / 带柔和倒影的台面）
→ 光线（柔光箱主光 + 侧逆光勾轮廓 + 底部补光，**无硬阴影**）→ 机位（平视或略俯，产品占画面 60–75%）
→ 画幅 → 画质词（商业摄影、高细节、真实材质）。

**易错**：背景别用花哨渐变抢主体；包装文字必须生成后逐字核对；产品占画面太小会显廉价。

**画幅**：`1:1` 或 `4:5`。

## lifestyle_scene —— 生活场景

**骨架**：产品外观（与参考图一致）→ 环境（地点、陈设、道具、材质）→ 使用状态（手、动作、
人与产品的关系）→ 光线（自然光 / 窗光 / 环境光，方向要明确）→ 机位与景深（产品清晰、背景自然虚化）
→ 氛围词。

**易错**：环境道具别抢主体；必须显式写「保持产品外观与包装与参考图一致」；场景里常需要人，
但**人脸容易抢焦点**——能只出手就只出手。

**画幅**：`4:5` / `3:4`（社媒），`16:9`（网站）。

## closeup_product_with_person —— 人手/局部特写

**骨架**：产品材质特写（质地、光泽、膏体/液体/粉末质感）→ 人手或局部（手指姿态、指甲、
肤色）→ 应用动作（涂抹 / 按压 / 倾倒 / 握持的**瞬间**）→ 光线（侧光或侧逆光突出质感，
**避免平光**）→ 极浅景深 → 画幅。

**易错**：人脸**不入画或只入局部**；手部容易崩，要显式要求「手指自然、结构正常、无畸形」；
质感是主角，光线要比 `product_shot` 更硬。

**画幅**：`1:1` 或 `4:5`。

## moodboard_pin —— 竖版情绪板

**骨架**：先声明竖版 2:3 构图 → 产品在画面中的位置（偏下或偏侧，**上部留出图文空间**）
→ 环境氛围（情绪板拼贴感、纸样材质、色卡、布料）→ 色调（统一低饱和 / 复古 / 奶油色）
→ 光线（柔和自然光）→ 画幅。

**易错**：必须显式声明 `2:3` 竖版；上方**留白**别塞满；别用强对比色，会破坏情绪板调性。

**画幅**：`2:3`。

## hero_banner —— 宽幅头图

**骨架**：先声明宽幅构图 → 主体位置（左右三分线，**另一侧留出文案空间**）→ 背景（能在超宽
比例下自然延伸，不空不挤）→ 光线（整体统一，突出主体）→ 色彩与品牌调性 → 画幅。

**易错**：主体居中会没地方放文案；背景要经得起 `21:9` 裁切；别在主体正上方压字。

**画幅**：`16:9`，超宽用 `21:9`。

## social_carousel —— 社媒轮播

**骨架**：第 1 张定调（配色、字体气质、版式网格、光线语言）→ 后续每张沿用同一视觉系统，
**每张承载一个独立信息点** → 生成后续图时把**第 1 张作为 `reference_images`** 锚定风格。

**易错**：整套视觉必须锁死；**不要把同一张图裁成不同比例充数**——那是假轮播。

**画幅**：`1:1` 或 `4:5`，**全套统一**。

## ad_creative_pack —— 广告变体组

**骨架**：先定卖点/钩子 → **每张一个不同的钩子或不同利益点** → 视觉系统统一（配色、字体气质）
→ 留出广告文案区（右下或底部）。

**易错**：变体要**真的换钩子**，不是换形容词；信息流里缩略图很小，**主体必须够大够清晰**。

**画幅**：`1:1`（信息流）/ `9:16`（短视频）/ `4:5`。

## virtual_model_tryout —— 虚拟模特试穿

**骨架**：模特设定（年龄段、气质、体型，与品牌受众匹配）→ **穿着状态（产品穿在身上 / 被使用，
且外观与参考图一致）** → 环境（影棚干净 / 户外自然 / 街拍 / 大片感 / 居家）→ 姿态与动态
→ 时装摄影光线 → 构图（全身 / 七分身 / 半身 / 产品部位特写）→ 画幅。

**易错**：必须**显式**强调产品「穿在身上 / 被使用」且「外观与参考图一致」，否则产品会变形走样；
人脸崩坏时的解法是**缩小人脸占比**（改成七分身或产品部位特写）。

**画幅**：`4:5` 或 `2:3`（时装），`1:1`（电商）。

## conceptual_product —— 概念超现实

**骨架**：产品 → 超现实设定（悬浮 / 飞溅 / 解构 / 雕塑化 / 包裹）→ **显式描述运动被冻结的那一帧**
→ 材质与物理感（水花、粉尘、碎片的形态与方向）→ 灯光（硬光塑体积，或影棚光）→ 背景
（纯色 / 渐变 / 深色）→ 画幅。

**易错**：**必须显式写「高速快门定格 / 运动被冻结的瞬间」**，否则模型会画出运动模糊；
悬浮要写清悬浮高度与**阴影落点**，不写就像贴图浮在画面上；飞溅元素别糊在产品本体上。

**画幅**：`1:1` 或 `4:5`。

## restyle —— 改风格

**骨架**：传原图作 `reference_images` → **只描述要改的审美 / 情绪 / 季节 / 色调** → 显式声明
要保留什么（「保持产品外观、包装、构图与主体位置不变」）→ 新色调与光线方案。

**易错**：**不要重新描述原图内容**（会导致重画）；保留项必须显式写出来，不写模型不保证保留；
改风格时别把产品包装一并改掉。

**画幅**：沿用与原图一致的比例。

## 追问脚本（D/E/F）

正文只放了 A–C 三类，剩下三类在这里。同样遵守：**最多 4 问、只给有标签的选项、上下文明确就跳过**。

### D 类 —— 上传了已有图，说「重做 / 换个感觉 / 出个别的版本」

→ 模式 `restyle`。

1. 想要哪种审美？`[干净清新 / 田园 / 静奢 / 暗调复古 / Y2K / 其他]`
2. 季节限定？`[圣诞 / 情人节 / 万圣节 / 黑五 / 无]`
3. 哪些要保留、哪些要改？（不明确时才问）

### E 类 —— 产品要上身（服装、配饰）

→ 模式 `virtual_model_tryout`。

1. 模特类型？（按品牌受众给 2–3 个具体选项）
2. 环境？`[影棚干净 / 户外自然 / 街拍 / 大片感 / 居家]`
3. 构图？`[全身 / 七分身 / 半身 / 产品部位特写]`

### F 类 —— 需求含糊，不知道要什么

例如「给我想点酷的东西」。

1. 具体是什么产品 / 什么主题？
2. 目标是什么？`[要上架卖 / 打品牌认知 / 投付费广告 / 更新官网]`
3. 能上传一张参考图吗？

问完之后**回到 D 类或 A–C 类**继续。
